# TO–G4 Contact Analysis

This directory contains scripts for analyzing contacts between Thiazole Orange (TO) and G-quadruplex DNA.

## Method

- Only heavy atoms are included in the contact calculation.
- A distance cutoff of 4.5 Å is used to calculate residue-level contact frequency.
- A distance cutoff of 5.0 Å is used to classify TO as being in a bound state.
- Contact frequencies are calculated for individual DNA residues.
- Results from independent replicates can be summarized as mean values and standard deviations.
