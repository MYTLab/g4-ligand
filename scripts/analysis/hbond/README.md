# Hydrogen-Bond Analysis

This directory contains scripts for analyzing hydrogen bonds between Thiazole Orange (TO) and G-quadruplex DNA.

## Method

Hydrogen bonds are identified using the following geometric criteria:

- Donor–acceptor distance: ≤ 3.5 Å
- Donor–hydrogen–acceptor angle: ≥ 150°
- TO residue name: `TOG`

The analysis reports:

- Overall hydrogen-bond occupancy
- Mean hydrogen-bond count
- Per-residue hydrogen-bond occupancy
- Mean and standard deviation across independent replicates
