# TO–Terminal Guanine van der Waals Analysis

This directory contains scripts for calculating residue-level van der Waals interactions between Thiazole Orange (TO) and terminal guanine residues of the G-quadruplex.

## Method

The analysis focuses on interactions between TO and guanine residues in:

- The upper terminal G-tetrad
- The lower terminal G-tetrad

Per-residue van der Waals interaction energies are calculated to determine which terminal guanine residues contribute most strongly to TO binding.

The analysis is intended to complement:

- Contact-frequency analysis
- π–π stacking analysis
- Hydrogen-bond analysis
- MM/GBSA binding-energy decomposition
